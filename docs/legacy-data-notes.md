# 竞观 · 行情工作台

已接入真实的A股报价、竞价时段分钟价格、普通分时、A股行业／概念板块，以及美股行业样本统计。竞价分钟曲线不代表逐笔虚拟参考价；匹配量、未匹配量及方向尚未提供，不能把当前版本当成完整的实时竞价监控系统。

## 打开方式

使用Python 3.10或以上版本（已在Python 3.11验证），在项目目录运行，无需安装第三方Python包或前端依赖：

```powershell
python server.py
```

然后在新版Edge、Chrome或Firefox地址栏输入 `http://127.0.0.1:8000`。停止服务时按 `Ctrl+C`。

不能用普通静态文件服务代替本后端；直接双击HTML只可操作本地配置，不能接入行情。如端口被占用，可运行 `python server.py --port 8001` 并访问对应端口。

默认仅对上游请求使用直连，不读取系统的 `HTTP_PROXY` / `HTTPS_PROXY`，也不修改系统代理。若需要通过自己的HTTP代理连接，可在当前PowerShell窗口设置：

```powershell
$env:MARKET_PROXY = "http://127.0.0.1:7890"
python server.py
```

代理不可用会明确提示失败，不会悄悄切换到其他连接方式。不要公开代理凭证；服务只绑定 `127.0.0.1`，不应直接公开到互联网。

## 已实现

- 自选默认使用列表视图，支持切换2／4／6宫格，不再提供9宫格。2宫格左右排列，4宫格两行两列，6宫格两行三列；窄屏自动转为两列或单列。无已保存视图或旧9宫格配置时使用列表，备用宫格为6宫格；已有合法2／4／6宫格偏好继续恢复，自选股票与原顺序不受影响。
- 列表每页20只，名称在上、代码在下，显示最新价、涨跌幅、所属行业及源时间；点击名称在当前页面打开已有详情，右侧按钮确认移除。保留分组、搜索和原自选顺序，不增加行情排序。列表与宫格选择以及原宫格数量分别保存在同一浏览器配置；空列表提供添加／清除搜索入口，窄屏表格横向滚动。
- 2／4／6宫格放大字体：名称16px、价格34px、涨跌幅16px、指标名称12px／数值14px，代码及时间状态11—12px；紧凑大屏规则不再缩小这些宫格字号。价格说明可换行，指标上下排布，窄屏允许正常纵向滚动；列表、板块看板和详情弹窗不受此字号调整影响。
- 输入6位股票代码自动识别当前支持的沪深A股市场，调用已有报价接口核实证券名称，成功后才允许保存；保留前导零，支持失败重试、去重和移除确认。新增股票的名称由接口自动填入，原有本地名称继续保留用于搜索。
- “全部自选”为固定汇总入口，默认提供重点观察、观察名单；支持新建分组、重命名默认及自定义分组，列表点击“自选分组”名称可调整股票归属。每只股票属于一个分组，分组ID稳定，改名不影响归属；按已添加的名称或代码搜索。
- 超过同屏数量后分页；拖动手柄排序，或聚焦手柄后按 `Alt + 左／右方向键`。
- 卡片放大、页面全屏及本机北京时间显示。
- 自选和布局保存在当前浏览器的 `localStorage`；不可用时明确提示仅本次会话有效。
- 东方财富A股真实报价及常规交易时段分时曲线；分时下方显示源成交量柱，不代表竞价量。
- 同屏支持“竞价走势／普通分时”切换，默认竞价走势：横轴09:15—09:25，展示源分钟价格；卡片另外标注最新普通报价及09:25之后的盘前价格记录，详情弹窗沿用所选图表。竞价模式不画成交量柱，普通分时保留红绿量柱。
- 普通分时在宫格和同一详情弹窗中显示两行八项指标：开盘价、最高价、最低价、换手率、成交量、成交额、振幅和报价量比。成交量按手／万手／亿手、成交额按元／万元／亿元展示；指标是最新报价快照，不是鼠标所在历史分钟的数据。
- 普通分时指标单独使用报价源时间；非今日报价标为历史，获取失败保留旧值并标记，缺失显示 `—`、有效零值正常显示。旧后端未返回指标字段时提示重启 `python server.py`，重启后强制刷新浏览器。
- 保留价格走势，其下新增上下量柱分区：上区未匹配量，下区虚拟匹配量。当前这两个量字段仍未核验接通，区域明确提示“真实量数据未接入”，不画模拟柱、不以普通成交量或价格变化替代；普通分时模式隐藏这两个竞价分区。
- 多宫格优先使用可用屏幕空间；屏幕较窄、提示换行导致高度不足时允许纵向滚动，不再把走势、量柱分区和指标强行挤叠。详情放大后显示完整布局。
- 卡片和详情新增“报价量比”，采用东方财富源量比值及报价源时间；失败保留旧值并标记，历史报价标记“历史”，不与竞价分钟曲线的时间混用。
- 点击自选卡片的放大按钮，在同一个竞价详情弹窗下方查看资金分类、历史资金及龙虎榜，无需另开页面；标题栏“资金分析”可直接跳转。
- A股行业／概念板块，分页展示涨跌幅、成交额和领涨股；涨跌板块数仅统计当前页。
- Nasdaq原始行业分类下的有效样本等权平均涨幅、样本数及领涨样本；不是官方行业指数，也不是行业ETF替代。
- 请求失败保留上次有效数据并标记异常，缺失值保留为空。切换页面会丢弃旧请求结果；后台标签页暂停采集。

## 数据边界

- A股使用东方财富公开网页接口，美股使用Nasdaq公开筛选器接口；不是交易所直连或已购买授权的正式数据服务，接口可用性、时效和使用范围仍需关注。
- 不使用模拟价格、示意价格曲线或虚构板块排行；`—` 表示未取得数据，不表示零。
- 新增自选先校验代码并向真实报价接口核实市场对应的证券名称，核验成功后再保存。市场代码识别不代表证券已存在，网络失败或未取得有效名称时保持不可保存并显示重试入口；核验成功不保证行情实时，完整竞价量依然未接通。已有自选报价失败继续保留旧值及失败标记。
- 报价响应中的 `auction_reference_price`、`auction_matched_volume`、`auction_unmatched_volume`、`auction_unmatched_side` 仍返回 `null`，`auction_verified` 为 `false`；不是零匹配量，也不是未匹配量为零。新增分钟曲线不会改变这些字段的核验状态。
- `/api/quotes` 新增 `volume_ratio`：沿用现有 `fltt=1` 请求模式，使用东方财富公开网页字段 `f50`，按其 `f152` 精度除以 `10 ** f152`，不使用价格精度 `f59`。公开网页字段映射及格式化函数、`fltt=1` 与 `fltt=2` 实际响应均已核对；本地不重新计算量比，也不使用“未匹配量÷匹配量”。
- `/api/quotes` 返回 `open_price`（`f46`）、`high_price`（`f44`）、`low_price`（`f45`），与现有价格一样按 `f59` 精度转换；`turnover_rate`（`f168`）和 `amplitude_pct`（`f171`）按 `f152` 精度转换为百分数，前端不再乘100。`volume_lots`（`f47`）单位为手，`turnover_amount`（`f48`）单位为元，两者不按价格精度缩放。无效、负值或精度异常的指标单独返回 `null`，不使其他有效报价失效；价格为零时仍按未提供处理。
- 源量比为零时显示 `0.00倍`；缺失、无效、负值或精度缺失时显示“未提供”，不冒充零。旧后端不返回 `volume_ratio` 时，指标提示重启本地服务；量比字段异常不会影响其他有效报价。
- 量比随普通报价的 `source_timestamp` 展示，不是09:25时刻的历史量比，也不随历史竞价曲线回放。缓存保留采集时间；网络失败时保留旧值并标记，源记录非今日时标记“历史”。
- `/api/trends` 新增 `auction_points`（09:15—09:25）、`preopen_result_points`（09:25之后且09:30之前）、`auction_source_timestamp`、`preopen_result_source_timestamp`、`trading_date`、`auction_data_version=1`；原 `points` 和 `source_timestamp` 仍只用于普通分时。竞价／盘前后段的 `minute` 为北京时间零点起算分钟，普通分时的 `minute` 仍是压缩午休后的0—240坐标。
- 上述分钟价格使用公开网页图表的价格字段，不是经核实的逐笔虚拟参考价；其中的源成交量不作为虚拟匹配量或未匹配量使用。源记录若为09:26，不会擅自改标为09:25成交结果；盘前后段只单列原时间价格，不能据此确认成交。
- 每次响应的三个时段只保留同一最新源记录日期，时间戳去重；历史竞价明确标记“非今日”。源没有竞价记录时不使用普通报价或上一日曲线补线。保留日期与源时间，缓存采集时间不冒充行情更新时间。
- 按北京时间工作日09:15—09:30窗口，每轮走势请求完成后间隔5秒刷新；其他时段间隔30秒。前端在窗口开始时提前唤醒，后端缓存也分为5秒／30秒，避免沿用窗口外的长缓存。此为请求节奏，不保证上游实时，法定休市日仍以源记录日期为准。隐藏标签页暂停，恢复后重新获取。
- 修改后须重启 `python server.py` 并刷新页面；旧后端不包含竞价字段时，会提示重启，不默默把普通分时当竞价。盘前实时可用性仍需在交易日开盘前实测。
- 普通分时只使用09:30—11:30和13:00—15:00记录，午休压缩为同一横轴位置。缺失分钟不补假数据，缺口以断线表示。
- 美股仅对有行业分类、有效涨跌幅的去重样本计算算术平均；显示覆盖数。筛选器缺少可靠源时间时显示“未提供”，不能据采集时间声称实时。
- 本机时间不是行情源时间，不能作为实时行情已更新的依据。
- 不提供买卖下单，不使用券商账号、代理密码或付费数据凭证。
- 本地文件打开和通过HTTP打开可能使用不同的浏览器存储空间；更换浏览器、访问地址或清除站点数据后，自选不会自动迁移。

## 刷新及缓存

- 报价：宫格当前可见最多9只，列表当前页最多20只，已打开但被筛选隐藏的详情股票仍单独保留订阅。每批最多9只、顺序获取，某批失败不阻塞后续批次；正常按整轮开始时间计算2秒目标间隔，耗时超过2秒则结束后至少等待250毫秒，不重叠发起新轮。后端每只报价缓存1秒。失败后等待4／8／16／最多30秒，成功恢复正常节奏。隐藏页及翻页／视图切换取消旧订阅，拒绝迟到响应。
- 全自选快照：独立于分页、搜索、行业与涨跌幅结果，按最多50只一批顺序扫描本机全部自选，正常目标每轮5秒，后端缓存4秒。后端单独限制该通道最多一个上游请求；失败后等待10／20／最多30秒。当前页更新、详情切换、空筛选结果不停止扫描；离开自选页、隐藏页面时取消，返回后重新获取。网络及上游限流可能使实际间隔更长，2秒／5秒不是源更新频率或行情延迟保证。
- 列表只获取当前页报价，不为20只股票加载走势图；打开详情后仅订阅该股票的走势，关闭详情后停止该单股走势订阅。列表模式的“竞价走势／普通分时”选择决定打开详情的图表类型，不改变列表始终采用最新报价的口径。
- 普通分时：最多3个前端并发请求，上一轮结束约30秒后刷新；后端缓存30秒。
- A股板块：每页50个，约30秒刷新；美股样本：约10分钟刷新及缓存。
- 后端统一限制最多4个上游请求并发。以上是本软件的采集间隔，不代表数据源以同等频率更新。
- 数据响应区分 `source_timestamp`（源时间）与 `fetched_at`（采集时间）；健康检查成功不代表上游可用。
- 仅在打开详情时请求该股票的资金及龙虎榜，关闭后停止刷新；隐藏标签页暂停，切换股票会取消旧请求。
- 资金分类约30秒刷新／缓存，历史资金缓存5分钟，龙虎榜约10分钟刷新／缓存；资金与龙虎榜独立加载，失败保留上次数据并标记旧数据。
- 当日明盘／暗盘快照仅在普通分时详情打开且页面可见时触发；后端共享榜单缓存，成功采集后约5分钟才允许新一轮采集，失败后约60秒允许重试。“刷新资金”同样遵守共享缓存，不为每只自选股重复拉取。采集中前端每3秒读取本地进度，不是每3秒向上游重新采集。

## 当日明盘／暗盘快照

- 在“普通分时 → 个股详情”的分时图下方、现有资金分类前显示明盘资金、暗盘资金、主力净流入（含暗盘）、暗盘活跃度，不新增页面，不改变竞价真实量尚未接通的状态。
- `/api/dark-flow?secid=1.600519` 返回指定股票的当日快照及共享采集状态。来源为东方财富当日暗盘资金榜公开网页数据通道；不携带用户凭证、不请求历史权限、不尝试绕过访问限制，公开通道可能变更、限流或停止提供数据。
- 字段映射依据源页面对应列：`7` 明盘资金、`6` 暗盘资金、`8` 主力净流入（含暗盘），金额按原页面单位元展示；`11` 为活跃度比例，乘100后以百分数显示。正值红色、负值绿色、零值中性色、缺失灰色；活跃度为金色。保留合法零值，异常或缺失不填零。
- 这些是模型测算的资金行为统计指标，不是交易所暗盘成交记录，也不是交易者身份识别。仅展示源资金值及正负方向，不反推出明盘、暗盘各自流入／流出总额；不把明盘、暗盘、主力及其他资金分类再次相加。
- 只接受北京时间当日的源榜单日期；休市、盘前无当日数据或返回上个交易日时显示不可用，不以历史记录填充当日。记录时间由源字段 `5` 的时分秒与当日日期组成，缺失或不合法时显示未提供；`fetched_at` 是对应分页采集时间，不冒充资金更新时间。
- 目前验证的是榜单分页通道，而非单股定向订阅。首次请求启动共享后台批次，每页100条，按源覆盖数量采集，最多100页、两个上游并发；每批设置60秒调度预算，已在途请求可能稍后完成。不会阻塞报价／分时接口，且仍受全局四并发约束。进度、未匹配、源失败、日期错误及不完整覆盖分别标记。
- 榜单实时排序会变化，分页不是同一时刻的完整市场快照，可能出现重复或遗漏；匹配时同时核对市场和股票代码，同一股票优先保留更新的有效源记录时间，不将未匹配解释为没有资金活动。刷新失败保留同日旧快照并标记，跨日清空；旧缓存不会伪装成本轮采集。
- 关闭详情、切回竞价或隐藏页面会停止前端请求，不再触发新批次；已启动的后台批次可能继续完成，但不会自行周期运行。重启后端清空内存缓存；该模块不提供历史曲线、下单或竞价量替代值。

## 自选分组与添加股票

- 分组栏提供“＋新建分组”“管理分组”，分组名为1—20个字符，拒绝空名称、控制字符、同名（忽略大小写）及保留名称“全部自选”；最多100个分组，包含两个初始分组。不提供分组删除，不擅自移除股票。
- 分组及股票归属存入原 `jingguan.workspace.v1` 的 `groups`／`stocks`，兼容没有 `groups` 字段的旧配置。恢复时校验名称、ID、重复项和股票格式；无效或未知归属转入默认分组，不因分组异常删除有效股票。存储失败时提示仅本次会话有效。
- 列表增加“自选分组”列，点击名称打开调整弹框；保存后保持自选原顺序，当前分组筛选结果和数量同步更新。添加股票时默认选中当前分组，汇总页默认重点观察；重命名后所有分组选项与列表名称同步更新。
- 代码路由当前仅覆盖 `60/68` 开头的沪市A股及 `00/30` 开头的深市A股。6位代码输入完整后等待250毫秒再调用现有 `/api/quotes`；根据返回 `secid` 和有效证券名称核验，不遍历其他市场猜测。北交所、基金、指数及其他代码不在本次自动识别范围内。
- 输入改变或关闭添加弹框立即取消旧核验，按请求代次和当前代码校验返回结果，旧响应不能覆盖新输入；保存再次核对已验证代码与市场，防止等待中或绕过按钮误添。失败可点击重新核验，不填模拟名称，不把未知证券当成有效自选。
- 添加弹框字号独立放大：标题20px、说明和字段标签15px、输入／选择16px、辅助文字13px、错误14px、底部按钮15px，输入框最小高度46px；不改变其他详情和原有看板字号。

## 列表报价及行业

- 列表及普通分时主价格采用单股报价与批量快照中源时间较新的记录，同一源时间优先批量快照；源时间都缺失时仅以采集时间选择展示，但不纳入涨跌幅筛选。最新价、涨跌幅来自同一记录，涨跌幅统一保留两位小数用于展示、方向判定与区间筛选，不使用竞价分钟图的选点价格。普通分时其余指标仍采用单股报价，并保留独立源时间。合法零涨幅显示 `0.00%`，缺失显示 `—`；源日期非北京时间当日标记“历史／非今日”，更新失败保留旧值并标记。源时间倒退或缺失不覆盖该通道已有较新有效时间的记录。
- 行业字段取单股报价接口的 `f127`，或批量 `ulist.np/get` 接口的 `f100`，按源原分类展示（如白酒Ⅱ、电池），不使用概念板块推断行业。上述字段来自不同接口，不能互换。批量接口 `fltt=2` 的 `f2` 是最新价、`f3` 已为百分数，`f12/f13` 是证券代码／市场，`f14` 名称、`f124` 源时间，不再乘100。证券代码和市场须与本次请求匹配，异常或重复行不会当作有效快照。
- 涨跌幅支持全部／上涨／下跌／平盘／自定义区间。只对北京时间当日且有效的源涨跌幅应用数值筛选，缺失及非今日不当作平盘；“全部”保留旧值或缺失记录并标记。区间包含边界，可留空一侧；非数字、非有限值及最低大于最高会报错，原条件不变。自定义输入需点击应用，其他方向选择立即生效。
- 行业Tab仅分类已添加的全部自选；“待分类”表示尚未取得行业字段，“未提供”表示源明确未给有效行业，不推测补齐。分组、名称／代码搜索、涨跌幅与行业条件组合生效，列表和宫格共用同一结果及原自选顺序。Tab数量在应用所选行业之前统计，选择一个行业不会隐藏其他可切换行业；已选行业暂时无匹配时保留零数量入口。改变条件回到第一页；清除筛选仅重置涨跌幅及行业，不清空自选、原分组和搜索。新增股票会清除行情筛选及搜索，以便显示新自选。
- 页面同时显示源记录时间、记录年龄、实际采集时间及最近完成请求尝试时间；记录年龄不是端到端传输延迟，源时间未变也不直接判定断流。不根据固定秒数断言停牌／断连。升级后须重启 `python server.py` 并强制刷新浏览器；旧后端缺少快照接口时会明确提示，不伪装成已取得完整行业分类。

## 资金与席位口径

- 当前资金分类来自东方财富公开网页接口，主力净额／占比取 `f62/f184`，超大单 `f66/f69`，大单 `f72/f75`，中单 `f78/f81`，小单 `f84/f87`。流入／流出分别取超大单 `f64/f65`、大单 `f70/f71`、中单 `f76/f77`、小单 `f82/f83`，金额单位为元。
- 主力是超大单＋大单的汇总。主力流入／流出仅在两个子项均有效时相加；主力净额与净占比保留源值，不再次加总主力与其子项。
- 分类依据成交单规模，不直接识别机构、游资或散户账户。仅显示“价格上涨／主力净流出”等事实组合，不断言出货、洗盘或实际资金意图。
- `f124` 是源行情时间，页面明确标为非逐笔资金更新时间；不把采集时间或本机时间当作资金更新依据，也不承诺实时。
- 历史日线请求 `f51` 至 `f63`：日期、主力、小单、中单、大单、超大单净额依次为前六列。排除本机北京时间当日及未来日期，对实际返回记录按日期去重排序。
- 近5／10／20条交易日记录显示统计起止日期与有效样本数。样本不足或主力净额缺失时累计显示 `—`，不将不足20条的数据标为完整20日累计；日图缺失标为×，不补零。
- 龙虎榜查询近90个自然日内最新上榜交易日，按上榜原因分别展示。买／卖榜同一席位的相同披露只展示一行，并合并“买榜／卖榜”标记；不同原因、不同金额的机构记录不合并、不作跨原因汇总。
- 每个上榜原因的席位表上方显示“展示席位买入合计／卖出合计／买卖总差值”，差值为买入减卖出。沿用后端去重结果，每行仅统计一次，不因同时列入买榜和卖榜而重复累计。金额按分四舍五入后以安全整数累计，避免浮点尾差；正差值红色、负差值绿色，零值中性色。部分披露获取失败、金额缺失或超出安全整数范围时三项均显示 `—`，不把缺失当零。该汇总仅覆盖当前上榜原因下的展示席位，不是该股票全天交易或跨原因合并的官方汇总；更新失败保留的旧披露仍按原时间标记。
- 龙虎榜“机构专用”只表示披露类别，不识别具体机构；沪／深股通专用标为交易通道。暂无披露不表示没有机构或游资交易，历史上榜不表示今天仍在交易。
- 东方财富返回 `code=9201`、`result=null` 且明确“返回数据为空”时按暂无记录处理；网络或其他接口失败单独提示，避免把失败误报为没有上榜。

### 游资关联标签

`seat-labels.json` 是本机维护的公开席位关联名单，不会自动从传闻中推断身份。**初始名单为空**：目前没有内置经核验的具体游资关联，未匹配时显示“游资未识别”，不虚构人名。

仅在核对可靠公开资料后添加关联。每条记录必须包含下列字段；席位代码与原名称均精确匹配，且上榜交易日落在有效期内，才展示“游资公开关联”标签：

```text
department_code  数据源原席位代码
department_name  数据源原完整席位名称
alias            公开使用的游资名称／昵称
evidence_url     可核验公开资料的HTTPS地址
evidence_date    资料日期，YYYY-MM-DD，不允许未来日期
valid_from      关联适用开始日期，YYYY-MM-DD
valid_to        关联适用结束日期，YYYY-MM-DD
```

将经核验的记录放入JSON根对象的 `associations` 数组。程序校验字段、地址和日期格式，但**不能自动验证资料真实性**；操作者仍需核验来源及适用时间，不应把论坛传闻当作证据。格式无效会停用全部关联标签并提示，不影响原始披露。标签展示资料日期，点击可查看来源；即使存在关联，也不确认本次实际交易人或个人账户行为。该配置不会通过静态服务公开。

## 竞价原始盘口核验

`auction_probe.py` 是独立的原始盘口采样工具，不替代网页版，不修改当前图表，也不将普通盘口量认定为虚拟匹配量／未匹配量。无需安装新依赖，不需要先启动 `server.py`；复用其网络请求、超时、代理及证券代码校验。采样股票由命令指定，不会自动读取浏览器中的自选。

立即采一轮，只检查连通和原始字段，不受时间窗口限制：

```powershell
python auction_probe.py --secids "1.600519,0.300750" --once
```

在实际交易日上午09:14前启动，等待当天北京时间09:14开始采样，在09:26停止发起请求：

```powershell
python auction_probe.py --secids "1.600519,0.300750"
```

- 支持1至9只不同股票，重复代码去重；沪市代码格式为 `1.600519`，深市为 `0.300750`。建议至少同时包含一只沪市和一只深市股票，并根据需要扩展为6至9只。
- 每轮完成后等待5秒，最多4个采样请求并发。09:26后不再发起请求，已经发出的请求可能稍后返回并落盘；不会把采集间隔称为行情更新频率，也不保证实时。`--once` 只采一轮，不开启循环或后台任务。
- 常规模式仅针对启动当天的窗口；09:14至09:26之间启动只能采到启动后的数据，窗口结束后启动会报错退出，周末也会拒绝。不会自动安排下一交易日或补回早前历史；不内置交易所节假日日历，需自行确认实际交易日。
- 请求保留 `f531/f532` 盘口字段组，以及交易状态 `f292`、源时间 `f86`、价格精度 `f59`、盘口价量和普通成交量／额等原字段。原始响应存入 `raw_fields`，字段缺失另列 `missing_fields`；源值为 `null`、`-` 或零时保留原值，不按缺失补零。源时间单独校验为 `source_timestamp`，与 `request_started_at`／`fetched_at` 区分；源时间异常不会抹掉原始 `f86`。
- 每次运行新建 `auction-probe-data/本机北京时间日期/时分秒-唯一标识.jsonl`，不覆盖已有样本。首行为 `kind=session` 的运行信息，后续为 `kind=snapshot` 的原始快照或 `kind=error` 的失败记录，每条写入后刷新缓冲。重复源时间仍保留用于核对更新情况，不视作新增成交。写盘失败会停止，不悄悄丢样本。
- 所有记录都保持 `auction_verified=false`；不会将买一量、买二量等字段重命名为竞价量，不推断数量单位或未匹配方向。快照条数只表示采到了原始响应，不代表字段完整、今天有竞价数据或竞价语义已经验证；盘中 `--once` 样本不能证明开盘竞价量可用。
- 采样器独立运行时，关闭网页不影响采样；但必须保持采样进程运行、电脑唤醒且网络可用。按 `Ctrl+C` 停止后保留已写入记录，不会创建计划任务或自动重启。采样文件不在本地HTTP服务的静态白名单中，不增加下载接口。
- 退出码 `0` 表示至少取得一条原始快照且没有采样错误，`1` 表示全部失败、部分错误或写盘异常，`2` 表示参数／启动窗口不符，`130` 表示手动停止。间歇失败仍会记录并继续后续轮次，不将失败当作无竞价或零数量。

拿到真实交易日上午的样本后，仍需分别核对沪深的交易阶段、源时间与日期、字段含义、数量单位、停牌／缺失／延迟场景，再决定是否接入现有量柱。原始采样不等于经核验的逐笔竞价数据，也不自动获得数据使用授权。
